# Draftly Demo Checklist

- [ ] Backend starts successfully.
- [ ] `http://localhost:8080/api/health` returns `UP`.
- [ ] Swagger opens at `http://localhost:8080/swagger-ui/index.html`.
- [ ] Gmail API OAuth is configured.
- [ ] Extension loads in `chrome://extensions`.
- [ ] Gmail is opened fresh after extension reload.
- [ ] Draftly button appears in Gmail reply editor.
- [ ] Draft generation works.
- [ ] Draft is inserted into Gmail editor.
- [ ] Regenerate works through backend API or UI if available.
- [ ] Approve works through backend API or UI if available.
- [ ] Reject works through backend API or UI if available.
- [ ] Save as Gmail Draft works.
- [ ] Tone profile updates after approve.
- [ ] No duplicate Draftly buttons appear.
- [ ] No real secrets are committed.
