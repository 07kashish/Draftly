# Draftly Backend

This folder contains the Spring Boot backend for Draftly - Gmail AI Reply Agent.

For full project setup, API endpoint details, environment guidance, and project status, see the root [README.md](../README.md).

## Run

```bash
mvn spring-boot:run
```

Swagger UI is available at:

```text
http://localhost:8080/swagger-ui/index.html
```
